# امضای دیجیتال قراردادها

برای امضای محلی، پلتفرم از Ed25519 استفاده می‌کند. پیش از امضا، Digest پایدار
SHA-256 از شناسه، Tenant، نوع، طرف‌ها، شرایط و متن قرارداد ساخته می‌شود. امضا
به همان Digest وابسته است؛ بنابراین تغییر هر بخش قرارداد باعث نامعتبرشدن Verify
می‌شود.

APIها:

- `POST /api/v1/contracts/:id/sign`
- `GET /api/v1/contracts/:id/verify`

اطلاعات قابل ثبت در هر امضا شامل الگوریتم، Digest، امضا، کلید عمومی و زمان امضا
است. کلید خصوصی هرگز در API response یا متن قرارداد برگردانده نمی‌شود.

`LocalEd25519SignatureProvider` برای محیط توسعه و تست است. در محیط Production باید
همین Interface به سرویس امضای مورد تأیید سازمان یا ارائه‌دهنده‌ی e-signature
متصل شود و کلید خصوصی داخل KMS/HSM یا زیرساخت امن همان ارائه‌دهنده بماند. این
پیاده‌سازی به‌تنهایی گواهی حقوقی امضای الکترونیکی محسوب نمی‌شود و جایگزین بررسی
الزامات محلی توسط مشاور حقوقی نیست.
